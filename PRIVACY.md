# Política de Privacidade — LOLLIFLIX

**Última atualização:** 23/09/2026

O LOLLIFLIX é um aplicativo reprodutor de mídia (player) que permite ao usuário
acessar o conteúdo do seu próprio provedor/painel IPTV (padrão Xtream Codes).

## Dados que o app usa
- **Usuário e senha do seu provedor IPTV:** ficam armazenados **somente no seu
  aparelho** (armazenamento local do app) para permitir o login automático.
  Não enviamos essas informações para nós nem para terceiros.
- **Preferências locais:** favoritos, histórico e configurações ficam apenas no aparelho.

## Dados que o app NÃO coleta
- Não coletamos dados pessoais para nossos servidores.
- Não usamos rastreadores de publicidade.
- Não vendemos nem compartilhamos dados com terceiros.

## Comunicação com a internet
O app se conecta **diretamente ao servidor/painel IPTV que você configura** para
autenticar e reproduzir o conteúdo. O uso desse serviço está sujeito aos termos do
seu provedor. O LOLLIFLIX não hospeda, fornece nem controla nenhum conteúdo.

## Conteúdo
O LOLLIFLIX é apenas um player. Todo o conteúdo exibido é fornecido pelo painel/
provedor configurado pelo próprio usuário, que é o único responsável pela
legalidade e pelos direitos do conteúdo acessado.
